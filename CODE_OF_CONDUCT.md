# Code of conduct

This project is a technical collaboration space. Participants must be
respectful, precise, and constructive in issues, pull requests, reviews,
discussions, and other project channels.

Harassment, discrimination, threats, deliberate disclosure of private data,
credential sharing, and sustained disruptive behavior are not accepted.
Disagreement about security or architecture is welcome when it addresses the
evidence and treats people with respect.

Report conduct concerns privately to the maintainer through GitHub. The
maintainer may edit or remove content, close interactions, or temporarily or
permanently restrict participation when necessary to protect the community.
Enforcement decisions will consider context, impact, repeated behavior, and
the safety of affected participants.
