# Support

Use GitHub Discussions for usage questions, configuration help, and design
exploration. Use the structured issue forms for reproducible bugs and scoped
feature requests.

This is pre-release software with no service-level guarantee. Include the
version or commit SHA, provider, platform, command, and a minimal public
reproducer. Never include credentials, private workflow source, or unredacted
runner evidence. Vulnerabilities must follow [SECURITY.md](SECURITY.md).
